# Market-ready Checklist

## Functional readiness

- [x] FAQ automation
- [x] Menu browsing
- [x] Order placement
- [x] Order tracking
- [x] Appointment/table booking
- [x] Lead capture
- [x] Human handoff request
- [x] Feedback capture
- [x] Conversation history
- [x] Analytics dashboard
- [x] CSV export

## Client onboarding checklist

Ask client for:

- Business name
- WhatsApp number
- Location
- Opening hours
- Menu/services
- Prices
- Delivery/pickup rules
- Booking rules
- Cancellation/refund rules
- FAQs
- Staff escalation contact

## Security checklist

- [ ] Strong admin password
- [ ] Strong secret key
- [ ] HTTPS only in production
- [ ] Signature validation for Twilio
- [ ] Meta tokens stored as secrets
- [ ] Database backups
- [ ] Admin access limited
- [ ] No customer-sensitive data in GitHub

## WhatsApp compliance checklist

- [ ] Collect customer opt-in before business-initiated messages
- [ ] Use approved templates for outbound business-initiated messages
- [ ] Provide clear stop/help path
- [ ] Avoid spam
- [ ] Keep chatbot focused on business support
- [ ] Escalate complex complaints to humans

## Portfolio checklist

- [ ] GitHub repository
- [ ] README with screenshots
- [ ] Architecture diagram
- [ ] Demo video
- [ ] WhatsApp screenshot
- [ ] Admin dashboard screenshot
- [ ] Dataset explanation
- [ ] Case study PDF/doc
