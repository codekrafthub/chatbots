## Problem statement

The client was receiving repeated questions about menu, delivery, booking and order status. Staff time was spent answering the same questions manually. The business needed a faster WhatsApp support workflow.

- FAQ automation

- Lead capture
- CRM/database storage
- Analytics dashboard
- Admin control panel

## Solution architecture

WhatsApp/Twilio/Meta webhook → Flask app → Bot engine → SQL database → Admin dashboard.

## Lessons learned

- Keep WhatsApp messages short and action-oriented.
- Use structured SKUs for reliable order parsing.
- Always provide a human handoff.
- Keep client data in simple CSVs for easy onboarding.
